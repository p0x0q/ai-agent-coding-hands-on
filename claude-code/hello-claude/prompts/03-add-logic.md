# ステップ3: ロジックの追加

このステップでは、JavaScriptを使ってタスクリストアプリに機能を追加します。

## 学習ポイント

- JavaScript実装のプロンプティング
- 段階的な機能追加
- デバッグの依頼方法

## 実行手順

### 1. 基本的なタスク追加機能

まずは、タスクを追加する機能を実装します：

```
script.jsに、タスクを追加する機能を実装してください。

要件：
1. DOM要素の取得：
   - 入力フィールド
   - 追加ボタン
   - タスクリスト（ul要素）

2. タスク追加機能：
   - 追加ボタンをクリックしたら実行
   - 入力値が空の場合は何もしない
   - 新しいliタグを作成
   - タスクテキストを表示
   - タスクリストに追加
   - 入力フィールドをクリア

3. Enterキーでも追加できるようにする

コードには適切なコメントを付けてください。
```

### 2. 動作確認

ブラウザをリロードして、以下を確認：

1. 入力フィールドにテキストを入力
2. 「追加」ボタンをクリック
3. タスクが一覧に表示される
4. 入力フィールドがクリアされる

### 3. タスク削除機能の追加

次に、削除機能を追加します：

```
script.jsを修正して、タスク削除機能を追加してください。

要件：
1. 各タスクに削除ボタンを追加
   - ボタンのテキスト: "×" または "削除"
   - ボタンのclass: "delete-btn"

2. 削除ボタンをクリックしたら：
   - そのタスク（li要素）を一覧から削除

3. 削除ボタンのスタイルも styles.css に追加：
   - 小さめのボタン
   - 赤系の色
   - タスクの右側に配置
   - hover時に色が濃くなる

既存の機能は維持してください。
```

### 4. LocalStorageで永続化（応用）

ページをリロードしてもタスクが残るようにします：

```
script.jsにLocalStorageを使った永続化機能を追加してください。

要件：
1. タスク追加時：
   - LocalStorageに保存

2. タスク削除時：
   - LocalStorageから削除

3. ページ読み込み時：
   - LocalStorageからタスクを読み込んで表示

4. データ形式：
   - タスクの配列をJSON形式で保存
   - キー名: "tasks"

実装方法について、コメントで説明を加えてください。
```

## 確認事項

すべての機能が実装できたら、以下を確認：

### 基本機能
- ✅ タスクを追加できる
- ✅ 空の入力は追加されない
- ✅ Enterキーで追加できる
- ✅ 追加後、入力フィールドがクリアされる

### 削除機能
- ✅ 各タスクに削除ボタンがある
- ✅ 削除ボタンをクリックするとタスクが消える

### 永続化（実装した場合）
- ✅ タスクを追加してページをリロードしても残っている
- ✅ タスクを削除してリロードすると、削除されたまま

## デバッグのプロンプト例

### 機能が動かない場合

```
タスク追加機能が動きません。

症状：
- ボタンをクリックしても何も起こらない

コンソールエラー：
[ブラウザのコンソールに表示されるエラーを貼り付け]

現在のscript.jsのコード：
[コードを貼り付け]

問題を特定して修正してください。
```

### 意図しない動作の場合

```
タスク削除時に、他のタスクまで消えてしまいます。

期待する動作：
- クリックした削除ボタンのタスクだけが消える

実際の動作：
- 全てのタスクが消える、または最初のタスクだけ消える

該当部分のコード：
[削除機能のコードを貼り付け]

修正してください。
```

## よくある問題と解決策

### 問題1: ボタンが反応しない

**確認ポイント**：
- JavaScriptファイルが読み込まれているか
- `defer`属性が設定されているか
- コンソールにエラーが出ていないか

**Claude Codeへの質問例**：
```
script.jsが読み込まれているか確認する方法と、
イベントリスナーが正しく設定されているか確認する
デバッグコードを追加してください。
```

### 問題2: 削除ボタンが効かない

**原因**: 動的に追加した要素にイベントが設定されていない

**Claude Codeへの質問例**：
```
動的に追加したタスクの削除ボタンが動作しません。
イベントデリゲーションを使って修正してください。
```

### 問題3: LocalStorageのデータが壊れた

**Claude Codeへの質問例**：
```
LocalStorageをリセットするヘルパー関数を追加してください。
開発者ツールのコンソールから呼び出せるようにしてください。
```

## 応用課題

基本機能が完成したら、以下に挑戦：

### 1. タスク編集機能

```
タスクをダブルクリックすると編集できるようにしてください。

要件：
- タスクテキストをダブルクリック
- 入力フィールドに変換
- Enterキーで保存
- Escキーでキャンセル
- LocalStorageも更新
```

### 2. 完了/未完了の管理

```
各タスクにチェックボックスを追加してください。

要件：
- チェックボックスをクリックで完了/未完了を切り替え
- 完了したタスクは打ち消し線（text-decoration: line-through）
- 完了状態もLocalStorageに保存
```

### 3. フィルター機能

```
タスクをフィルタリングする機能を追加してください。

要件：
- ボタン3つ: 「すべて」「未完了」「完了済み」
- クリックで表示を切り替え
- アクティブなボタンを視覚的に区別
```

### 4. タスクの並び替え

```
タスクをドラッグ&ドロップで並び替えられるようにしてください。

ヒント: HTML5 Drag and Drop APIを使用
```

```
コメントで変更点を説明してください。
```

```
確認ポイント：

```
