# ステップ1: UIの作成

このステップでは、タスクリストアプリのユーザーインターフェースを作成します。

## 学習ポイント

- より具体的なプロンプトの書き方
- HTML要素の構造化
- CSSでのスタイリング指示

## 実行手順

### 1. HTMLの内容を作成

以下のプロンプトをClaude Codeに入力：

```
index.htmlのbodyタグ内に、タスクリストアプリのUIを作成してください。

以下の要素を含めてください：

1. アプリのタイトル（h1タグ）
2. タスク入力エリア：
   - テキスト入力フィールド（placeholder: "新しいタスクを入力"）
   - 追加ボタン
3. タスク一覧表示エリア：
   - ul要素（id="taskList"）
   - 最初は空でOK

HTML5のセマンティックなタグを使用し、
各要素には適切なid/classを設定してください。
```

### 2. CSSでスタイリング

HTMLができたら、スタイルを追加します：

```
styles.cssに、以下のスタイルを追加してください：

デザインコンセプト：
- クリーンでモダンな見た目
- 中央寄せレイアウト
- 最大幅600px
- 適度な余白とパディング

具体的なスタイル：
1. 全体：
   - フォント: sans-serif
   - 背景色: 薄いグレー（#f5f5f5）
   - コンテナは白背景で、軽いシャドウ

2. タイトル：
   - 濃い色（#333）
   - 中央寄せ

3. 入力フィールド：
   - ボーダー: 1px solid #ddd
   - パディング: 10px
   - 角丸: 4px
   - 横幅を広めに

4. ボタン：
   - 背景色: 青系（#4CAF50など）
   - 白文字
   - ボーダーなし
   - パディング: 10px 20px
   - 角丸: 4px
   - hover時に色が濃くなる

5. タスクリスト：
   - リストスタイルなし
   - 各タスクアイテムに軽い背景と余白

シンプルで見やすいデザインでお願いします。
```

### 3. UIを確認

1. ローカルサーバーを起動：
   ```bash
   python3 -m http.server 8000
   # または
   npx serve
   ```

2. ブラウザで `http://localhost:8000` を開く

3. UIが表示されることを確認

### 4. デザインの調整（オプション）

見た目を調整したい場合：

```
styles.cssを以下のように修正してください：
- [修正点を具体的に記述]

例：
- ボタンの背景色を緑色（#4CAF50）に変更
- コンテナの幅を700pxに拡大
- タイトルのフォントサイズを大きく
```

## 確認事項

ブラウザで以下を確認：

- ✅ タイトルが表示されている
- ✅ 入力フィールドが表示されている
- ✅ 追加ボタンが表示されている
- ✅ タスク一覧エリアがある（まだ空）
- ✅ デザインが整っている

## プロンプトのコツ

### 具体的な指示

**色を指定する場合**：
```
✅ 良い例：
「背景色を薄いグレー（#f5f5f5）にしてください」

❌ 悪い例：
「背景色をいい感じに」
```

### デザインの参考を示す

```
styles.cssを、モダンなToDoアプリのような見た目にしてください。

参考にするデザイン要素：
- Google Keepのようなクリーンさ
- カードベースのレイアウト
- 柔らかい影とボーダー
```

## トラブルシューティング

### CSSが反映されない

1. ブラウザのキャッシュをクリア（Cmd+Shift+R / Ctrl+Shift+R）
2. `index.html`にCSSファイルが正しくリンクされているか確認
3. CSSファイルのパスを確認

問題が解決しない場合、Claude Codeに質問：

```
CSSが反映されません。考えられる原因と解決方法を教えてください。

現在のindex.htmlのheadタグの内容：
[headタグの内容を貼り付け]
```

### デザインが崩れている

```
現在のデザインが以下のように崩れています：
[問題の説明]

期待する見た目：
[期待する状態]

修正してください。
```

## 応用課題

基本的なUIができたら、以下に挑戦してみましょう：

1. **レスポンシブデザイン**
   ```
   styles.cssにメディアクエリを追加して、
   スマートフォンでも見やすいデザインにしてください。
   ```

2. **ダークモード**
   ```
   ダークモード用のCSSを追加してください。
   @media (prefers-color-scheme: dark) を使用
   ```

3. **アニメーション**
   ```
   ボタンにホバーアニメーションを追加してください。
   滑らかなトランジション効果で。
   ```
