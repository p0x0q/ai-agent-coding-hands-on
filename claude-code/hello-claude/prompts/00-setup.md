# ステップ0: プロジェクトのセットアップ

このステップでは、プロジェクトの初期設定とHTMLの骨組みを作成します。

## 学習ポイント

- Claude Codeの基本的な使い方
- プロンプトの書き方の基礎
- ファイル作成の依頼方法

## 作業ディレクトリについて

- **working-directory**: ここで実際に作業します（最初は空）
- **completed-example**: 完成形の参考実装（困ったときに参照）

## 実行手順

### 1. Claude Codeを起動

ターミナルで以下を実行：

```bash
cd working-directory
claude
```

### 2. プロジェクト構造の作成

以下のプロンプトをClaude Codeに入力してください：

```
シンプルなタスクリストアプリを作成します。
まず、以下のファイル構成を作成してください：

1. index.html - メインのHTMLファイル
2. styles.css - スタイルシート
3. script.js - JavaScriptファイル

index.htmlには、以下の基本構造を含めてください：
- HTML5ドキュメント宣言
- 日本語設定
- タイトル「タスクリスト」
- styles.cssとscript.jsへのリンク
- 基本的なbodyタグ（中身は次のステップで作成）

シンプルで学習しやすいコードにしてください。
```

### 3. 生成されたファイルを確認

Claude Codeがファイルを生成したら、確認してみましょう：

```bash
ls -la
cat index.html
```

### 4. （オプション）コードの説明を求める

生成されたコードの内容を理解するために、説明を求めることができます：

```
作成したindex.htmlの構造について説明してください。
それぞれの要素が何のためにあるのか教えてください。
```

## 確認事項

以下のファイルが作成されていることを確認：

- ✅ `index.html`
- ✅ `styles.css`
- ✅ `script.js`

`index.html`に以下が含まれていることを確認：

- ✅ `<!DOCTYPE html>`
- ✅ `<html lang="ja">`
- ✅ `<title>タスクリスト</title>`
- ✅ `<link rel="stylesheet" href="styles.css">`
- ✅ `<script src="script.js" defer></script>`

## トラブルシューティング

### ファイルが作成されない

Claude Codeがファイルを作成しない場合、より明確に指示しましょう：

```
index.html というファイルを新規作成し、
以下の内容を記述してください：
[具体的な内容]
```

### 期待と違う内容が生成された

具体的にどう修正してほしいか伝えましょう：

```
index.htmlを以下のように修正してください：
- [修正点1]
- [修正点2]
```

## ポイント解説

### 良いプロンプトの書き方

**明確な目的を伝える**：
```
✅ 良い例：
「タスクリストアプリのindex.htmlを作成してください。
 HTML5の標準的な構造で、日本語対応にしてください。」

❌ 悪い例：
「HTML作って」
```

**段階的に進める**：
```
✅ 良い例：
「まず基本的なHTML構造を作成してください。
 UIは次のステップで追加します。」

❌ 悪い例：
「アプリ全部作って」
```
