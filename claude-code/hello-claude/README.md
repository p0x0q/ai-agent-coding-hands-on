# Hello Claude - Claude Code入門

このサンプルでは、Claude Codeの基本的な使い方を学びます。簡単なアプリケーションを作成しながら、AI駆動開発の基礎を習得できます。

## 学習目標

- Claude Codeの起動と基本操作
- 効果的なプロンプトの書き方
- ファイルの作成と編集
- 簡単なWebアプリケーションの構築

## 前提条件

- Node.js v18以上がインストールされていること
- Claude Codeがインストールされていること
- 基本的なHTML/CSS/JavaScriptの知識

環境構築がまだの方は、[Getting Started](../../docs/getting-started.md) を参照してください。

## 所要時間

約30分

## プロジェクト概要

このサンプルでは、以下のシンプルなWebアプリケーションを作成します：

- **タスクリストアプリ**
- タスクの追加・削除
- シンプルなUI
- ローカルストレージで永続化

## ディレクトリ構成

```
hello-claude/
├── app/                    # アプリケーション本体（ここに作成）
│   ├── index.html         # メインHTMLファイル
│   ├── styles.css         # スタイルシート
│   └── script.js          # JavaScript
├── prompts/               # プロンプト・手順書
│   ├── 01-setup.md       # セットアップ手順
│   ├── 02-create-ui.md   # UI作成のプロンプト
│   ├── 03-add-logic.md   # ロジック追加のプロンプト
│   └── prompts.json      # 再利用可能なプロンプト集
└── README.md             # このファイル
```

## 進め方

### ステップ1: プロジェクトの準備

1. このディレクトリに移動
   ```bash
   cd claude-code/hello-claude
   ```

2. Claude Codeを起動
   ```bash
   claude
   ```

### ステップ2: プロンプトに従って実装

`prompts/` ディレクトリの手順書を順番に実行します：

1. [01-setup.md](./prompts/01-setup.md) - プロジェクトのセットアップ
2. [02-create-ui.md](./prompts/02-create-ui.md) - UIの作成
3. [03-add-logic.md](./prompts/03-add-logic.md) - ロジックの追加

各ステップで、記載されているプロンプトをClaude Codeに入力し、指示に従って開発を進めます。

### ステップ3: アプリケーションの実行

1. アプリディレクトリに移動
   ```bash
   cd app
   ```

2. ローカルサーバーを起動
   ```bash
   # Pythonを使用する場合
   python3 -m http.server 8000

   # Node.jsを使用する場合
   npx serve
   ```

3. ブラウザで確認
   ```
   http://localhost:8000
   ```

1. HTMLの骨組み作成

## よくある質問

### Q: Claude Codeが期待通りのコードを生成しない

A: プロンプトをより具体的にしてみてください。例えば：
- 使用したい技術を明示（例：「Vanilla JavaScriptで」）
- 期待する動作を詳しく説明
- コードの構造を指定（例：「関数型で実装」）

### Q: エラーが発生した

A: エラーメッセージをClaude Codeに伝えてください：
```
以下のエラーが発生しました。解決方法を教えてください：
[エラーメッセージ]
```

### Q: 機能を追加したい

A: 現在の状態を説明してから、追加したい機能を伝えましょう：
```
現在、タスクの追加と削除ができる状態です。
タスクの編集機能を追加してください。
```

## 応用課題

基本的な実装ができたら、以下の機能を追加してみましょう：

1. **タスクの編集機能**
   - タスクをダブルクリックで編集可能に

2. **完了状態の管理**
   - チェックボックスで完了/未完了を切り替え
   - 完了したタスクは打ち消し線

3. **フィルター機能**
   - すべて/未完了/完了済みでフィルタリング

4. **データの永続化**
   - LocalStorageを使用してデータを保存

5. **スタイルの改善**
   - より洗練されたデザインに
   - ダークモード対応

## プロンプトのヒント

### 機能追加の場合

```
現在のapp/script.jsに、タスク編集機能を追加してください。

要件：
- タスクをダブルクリックで編集モードに
- 入力フィールドに変換
- Enterキーで保存
- Escキーでキャンセル

既存の機能は維持してください。
```

### バグ修正の場合

```
タスク削除ボタンをクリックしても削除されません。

現在のコード：
[コードを貼り付け]

期待する動作：
削除ボタンをクリックしたら、該当のタスクが一覧から削除される
```
