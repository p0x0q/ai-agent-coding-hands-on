※今回はスムーズなハンズオン進行のため、claude --dangerously-skip-permissionsオプションで進行します。
これはAIの操作を全て許可するオプション(コマンド実行)のため、基本的には、` --dangerously-skip-permissions` オプションを利用しない方が安全です。ただし、Sandboxなど壊れても問題ない環境であれば問題ありません。

## 1. はじめに
キャッチアップするために、以下のプロンプトを打つ

```
現在のディレクトリ構成を読み取り、フロントエンド、バックエンドでどんな処理をしているのか教えてください。

```

## 2. コンテキスト管理

現在のコンテキスト残量を確認。
```
/context
```

やりとりが増えてきて、過去の情報を参照しなくても良い状態になったら、/clearを実行して、コンテキストをリセットしてください。
```
/clear
```

## 3. UI改修

具体的にUI改修をしたい時（スクリーンショットをとって、ドラッグアンドドロップか、クリップボードからの貼り付けで画像をアップロードしてください）。

```
こちら、現状のUIを改善したいです。以下のスクリーンショットを参考に、もっと全体的に明るい白基調のデザインにして、ユーザーが使いやすいように改善したいが、どのような改善方法があるか調査し、提案してください。

```

## 4. パフォーマンスチューニング

必ず、ASIS(現状)として、UIを貼り付けること。画像そのものがコンテキストとなり、どのような改善をすれば良いか必要な情報を渡すことができる。

```
現在、応答が非常に遅いです。レスポンス速度を改善するために、どのようなパフォーマンスチューニングが可能か提案してください。大半がLLM待機時間かと思われます。

```
